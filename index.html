        SERVER & HOSTING GUIDE

        Run "Tha Crib" On GitHub

        This game runs completely in the browser with 3D WebGL and zero backend server requirements! Deploy to GitHub Pages in 3 steps:

        01

        Create a Repository on GitHub

        Visit github.com/new and name it the-crib.

        02

        Push Local Files

        git init
git add .
git commit -m "Initialize Tha Crib 3D"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/the-crib.git
git push -u origin main
        03

        Enable Free GitHub Pages Server

        In your GitHub repository, open Settings → Pages. Under Branch, select main and save.

        Your 3D game will be live globally at: https://YOUR_USERNAME.github.io/the-crib/
